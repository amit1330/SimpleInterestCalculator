# 💰 Simple Interest Calculator

A simple and interactive calculator to compute **Simple Interest (SI)** based on user inputs for **Principal**, **Rate of Interest**, and **Time**.  
This project is ideal for beginners learning **HTML**, **CSS**, and **JavaScript**.

---

## 📌 Formula Used
The formula for calculating Simple Interest is:
SI = (P × R × T) / 100



Where:
- **P** = Principal amount (₹)
- **R** = Annual rate of interest (%)
- **T** = Time period (in years)
